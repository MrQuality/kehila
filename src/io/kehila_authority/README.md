# Kehila product authentication foundation

This component adopts the reviewed AUTH-001 authentication ownership units into
an independent Linux product package. Windows remains the intended client
platform. The experiment is unchanged; this package imports no experiment source
and exposes no diagnostic probe server.

The package owns protected startup assets, password work, volatile credentials,
CSRF/origin admission, bounded coordinator/driver lifetimes and TLS transport.
It has a product composition root and product SQL namespace. The certificate
validity window is independent of disposable experiment execution budgets.
Fixed audit-uncertainty replies retain ordinary outbound cleanup ownership.

This commit establishes component ownership and dependency adoption. The product
SQL installer, native project transaction adapter and project interface follow
within the [authenticated creation delivery](../../../docs/implementation/authenticated-project-authority.md).
Source presence or ordinary component tests do not qualify an installed product,
actual PostgreSQL/browser behavior or real-data use. Ignored provisioned tests
remain dependent on their actual fixture and assertions.

The authority declares Rust 1.88 independently of the root workspace. The
[dependency assessment](../../../docs/implementation/project-authority-dependencies.md)
records locked inputs, license selections, retained notices and dated advisory
query limits. Minimum-version execution remains separately unqualified.
